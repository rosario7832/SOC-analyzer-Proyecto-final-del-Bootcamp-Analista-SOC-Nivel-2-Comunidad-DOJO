# SOC-analyzer
Aplicación web que analiza logs de un SIEM en Excel, detecta fuerza bruta, escalamiento, movimiento lateral y otras anomalías, correlaciona incidentes con MITRE ATT&amp;CK y genera informes técnico y ejecutivo en PDF. Incluye dashboard interactivo e IA opcional. Todo se procesa en el navegador y no inventa hallazgos.
